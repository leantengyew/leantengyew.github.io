Reel Downloader

Save public Facebook reels to your computer or phone. Runs on your own machine — nothing is sent to anyone else's server.

Why this page can't do it by itself

Browsers block one website from fetching files off another. JavaScript running here is not permitted to reach facebook.com at all, so a static page like this one physically cannot retrieve a video.

Sites that claim otherwise are quietly sending your link to a server they operate. The tool below makes your own computer that server, which takes about a minute to set up and keeps your links to yourself.

Setup

1Make sure Python 3 is installed — python3 --version in a terminal. macOS and Linux already have it; on Windows get it from python.org.

2Download the tool and its recommended helper:

git clone https://github.com/leantengyew/leantengyew.github.io.git
cd leantengyew.github.io/reel-downloader
pip install -r requirements.txt

The pip install step is optional. It adds yt-dlp, which keeps up with Facebook's frequent page changes and makes downloads far more reliable.

On your computer

python3 reeldl.py https://www.facebook.com/reel/123456789

The video is saved to a downloads folder next to the script. Add -o ~/Movies to save elsewhere, or --audio-only for MP3.

On your phone

1Start the server on your computer:

python3 reeldl.py serve

2It prints an address like http://192.168.1.42:8080. Open that on your phone, on the same Wi-Fi.

3In the Facebook app, tap Share → Copy link on the reel, paste it into the page, and tap Download, then Save to device.

  • iPhone: the file lands in Files → Downloads. Open it there and share it to Photos to get it into your camera roll.
  • Android: it goes straight to your Downloads folder.

The server has no password, so use it on a network you trust and stop it with Ctrl+C when you're finished. --local-only restricts it to your computer.

If a reel won't download

The tool is signed in as nobody, so it only sees what a logged-out visitor sees. Private, friends-only, and age- or region-restricted reels will fail, and that's deliberate.

If a public reel fails, run pip install -U yt-dlp — Facebook changes its page structure often and that update usually resolves it.

Please download responsibly

Saving a public reel to watch offline is what this is for. The person who made the video still owns it, so re-uploading it or presenting it as your own isn't yours to do. Facebook's terms also prohibit bulk or automated scraping — this tool deliberately handles one reel at a time.
